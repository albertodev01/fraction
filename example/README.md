## Example

This is a simple Dart CLI application that analyzes fractions and mixed fractions. To run it, use this command from the `example/` folder:

```bash
dart run
```

The app asks whether you want to analyze a fraction or a mixed fraction, then prints details about the value you enter (such as its inverse, its reduced form, and whether it's proper). To create a standalone executable (such as an `.exe` file on Windows), run:

```bash
dart compile exe bin/fraction_example.dart
```

See the [dart compile](https://dart.dev/tools/dart-compile) documentation for more options.
